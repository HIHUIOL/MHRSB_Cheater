# MHRSB_Cheater

> 怪物猎人崛起：曙光（MHRSB）**怪异练成 + 护石** 配装器 & Switch 金手指生成工具（PWA）

纯前端 PWA，无需安装、无需联网即可离线使用。用于规划防具怪异炼成词条、护石技能与珠子孔位，并一键生成对应的 Switch 金手指代码。

在线地址：<https://hihuiol.github.io/MHRSB_Cheater/index.html>

---

## ✨ 功能特性

### 配装编辑
- **装备（位置 1~5）**：选择防具，逐条设置怪异炼成词条（防御-、防御+、耐性-、耐性+、孔位+、技能-、技能+），自动汇总怪异点数与孔位。
- **护石（位置 6）**：以搜索面板方式选择护石技能 1 / 2，支持**具体等级**选择（Lv1 ~ 上限），孔位与珠子独立设置。
- **武器（位置 7）**：固定 444 孔位，可插 3 个 4 级珠。
- **技能合计**：实时统计所有装备的技能等级与会心率，支持**折叠相同选项**、**增加对比**（多套配装横向对比）。
  - 对比时技能行**按列分组排序**：第 1 套配装拥有的技能排最前，其余技能再按"哪一列先拥有"依次往下排，同一档内按技能编号稳定排序。这样第一列不会夹杂一堆它没有的技能。
- **防具一览**：展示各部件的防御、耐性、孔位信息。

### 模式
- **普通模式（默认）**：允许减虚空技能，护石技能等级按你实际选择的等级计算。
- **极限模式**：所有装备孔位（含护石）均可插入**任意等级珠子**（如 1 级孔也能插 4 级珠）；同时**护石技能等级一律按 15 级计算**（实际挑选时列表也直接显示为 15）。
  - 切换模式**不影响**已设置的护石技能"选择项"，只影响其等级上限/显示。
  - 护石技能一栏在极限模式下显示的等级会变成 `15`（如 `伏魔耗命 15`）。

### 配装管理（我的配装）
- **保存 / 加载 / 重命名 / 删除** 配装（存于浏览器本地 IndexedDB，数据库名 `MHRSB_Cheater_db`）。
- **上移 / 下移**：自定义配装排序（顺序存于 `localStorage`）。
- **全部删除**：带二级确认（需手动输入 `DELETE`）。
- **导出全部配装**：导出为 JSON 文件。
- **导入配装**：
  - 方式一：选择 JSON 文件导入（支持「导出全部」生成的批量文件，以及单个配装文件）。
  - 方式二：粘贴**分享码**文本导入。
- **分享**：把单套配装压缩为分享码（前缀 `MHRSB1:`），一键复制。

### 金手指代码
- 在「代码」页一键生成 Switch 金手指文本，支持**复制代码**与**下载**。
- 可选「自动生成」「护石技能最大」开关。

### 技能一览
- 在「会心率」卡片下方，点「展开技能一览」按钮展开（**默认折叠**，状态存于 `localStorage`）。
- 展示全部技能（147 个），按分类分组；**点击任意技能**弹出该技能的**效果说明**（描述 + Lv1~LvN 效果）。
- 技能效果弹窗支持**点击外部关闭**、按 `Esc` 关闭。
- 网格自适应列数：手机 3 列 / 中屏 4 列 / 宽屏 5 列；较长的技能名会自动缩小字号，保证完整显示。
- 已装备的技能按钮为**实心高亮**。

### 其他
- **主题三态**：🌓 跟随系统 / ☀️ 白天 / 🌙 暗色（点顶栏按钮循环切换，选择存于 `localStorage`）。
- **未保存提醒**：编辑过程中关闭 / 刷新页面会提示确认，避免误丢配装。
- **响应式布局**：手机单列；桌面按屏幕宽度自适应列数（笔记本 4 列、宽屏 5 列）。
- **PWA**：可添加到主屏，Service Worker「网络优先 + 缓存兜底」，支持离线与无感自动更新。

## 🚀 使用方法

用现代浏览器（Edge / Chrome / Safari 等）打开 `index.html`，或访问在线地址。

### 配装流程
1. 设置**装备（位置 1~5）**：先选装备，再逐条选词条 / 技能。
2. 设置**护石（位置 6）**：点击技能框 → 搜索并选择技能 → 选择等级 → 「确认选择」；再设置孔位与珠子。
3. 需要时点右上角切换**极限模式**。
4. 在「技能合计」查看汇总，可「＋增加对比」横向对比多套配装。

### 生成并使用金手指
1. 切到「代码」页（底部栏「切换至代码」）。
2. 复制或下载生成的代码。
3. 把代码粘贴到金手指文件**最下方**：

   ```
   contents/0100559011740000/cheats/44C9289FBB51455F.txt
   ```

4. 打开金手指并勾选使用。

> ⚠️ **注意装备箱子位置**：默认 1~5 为防具（需先生成防具并开启怪异炼化），6 为护石（存在时会替换，不存在则自动生成）。

## 🔧 版本与发布

- 页面顶栏显示**程序版本**（`APP_VERSION`），点「检查更新」可检测新版本。
- 版本号维护于**三处，发布时必须同步修改**：

| 文件 | 变量 / 位置 | 示例 |
|---|---|---|
| `js/main.js` | `var APP_VERSION = "..."` | `"v6.2.5"` |
| `sw.js` | `const CACHE = '...'` | `'MHRSB_Cheater-v6.2.5'` |
| `index.html` | `css/style.css?v=...` | `?v=6.2.5` |

> 修改 `style.css` 后务必同步更新 `index.html` 里的 `?v=` 查询串，否则浏览器可能使用旧样式缓存。

### Service Worker 行为
- **安装**：预缓存 `ASSETS` 清单（单个资源失败不影响整体）。
- **激活**：清理非当前版本的所有旧缓存。
- **请求**：网络优先，失败回退缓存；导航请求兜底到 `index.html`。
- 主线程监听 `controllerchange`，新版本接管后**自动无感刷新**。

## 🛠️ 本地开发

纯静态项目，任选其一：

```bash
# 方式一：直接用浏览器打开
打开 index.html

# 方式二：起一个本地静态服务器（推荐，便于测试 PWA / SW）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> 直接用 `file://` 打开时，Service Worker 无法注册（属正常现象），其余功能不受影响。

## 📝 说明

- 所有数据保存在**浏览器本地**（IndexedDB + localStorage），不上传服务器。
- 分享码使用 `gzip + Base64` 压缩，仅兼容**最新版本**生成的分享码。
- 编辑器自动生成的备份目录 `.backup/`（含 `*.bak-*`）不参与运行，可安全删除。
